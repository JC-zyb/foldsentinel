# FoldSentinel

文件夹哨兵：使用 Rust + Tauri 2 构建的开源 Windows 文件保护工具。支持中英双语、文件 / 文件夹流式密码加密包、串行任务队列、完整验证后的内容预览、历史与重试，以及可恢复的隐藏、NTFS 锁定、只读保护。

## 使用 v0.8.0（预览版）

当前版本为 **v0.8.0 预览版**，加入卸载安全检查并优化界面布局，保留 NTFS 锁定、权限只读、本地恢复备份及可选 SYSTEM 服务密码访问。Windows x64 安装包、便携 ZIP 与校验和见 [v0.8.0 发布页](https://github.com/JC-zyb/foldsentinel/releases/tag/v0.8.0)；发布说明列出对应提交的 Windows CI 与实际验证边界。也可按下文“开发与构建”从源码生成产物，本轮本机验证和未覆盖范围见[验证记录](docs/VALIDATION.md)。

系统需要 Windows 10/11 x64 与 Microsoft Edge WebView2 Runtime；安装器可按需获取 Runtime，便携版需提前具备 Runtime。当前版本未做代码签名。

1. 右上角选择 **简体中文 / English**；首次使用遵循系统首选语言，选择会在重启后保留。
2. 在 **创建加密包 / Encrypt** 中选择多个文件、文件夹或直接拖入窗口；分次选择或拖入会追加并去重，也可展开 **手动输入或编辑路径 / Enter or edit paths**，每行填写一个完整路径。下方清单可逐项移除或清空；重复与父子目录重叠会提示，须消除重叠再加入队列。可选输出目录，留空使用各源文件的父目录；加密文件夹的输出必须位于源目录之外。
3. 输入并确认这一批任务使用的密码，点击 **加入队列 / Add to queue**，检查每项输出建议，再点击 **开始 / 继续队列 / Start / resume**。自动避开已有名称，最终仍禁止覆盖。
4. **恢复加密包 / Restore** 与 **验证与预览 / Verify & preview** 也支持批量加入。完整认证 v1/v2 内容、检查归档结构和终块后才显示内容清单，不创建恢复文件或临时明文。每页 50 项，最多保留前 1,000 项及 256 KiB 路径名，超限明确提示；总量仍统计完整包。单文件格式没有保存原文件名，会明确显示为单文件内容。仍建议实际恢复并核对重要文件。
5. 长任务显示阶段、字节、速度及预计剩余时间，可取消当前任务、取消等待任务，或在当前任务后暂停队列。提交开始后不可取消；关闭窗口先暂停队列并请求取消，清理后可再次关闭。
6. 当前队列与折叠的历史记录分别显示，记录保存在本机 WebView2 用户数据中，最多保留 200 项；可清空历史，不会删除源文件。密码、密钥和预览清单不写入历史；预览只保留最近一次验证结果，关闭、切换操作或运行新任务会清除。等待任务只在进程内存中暂存密码，结束或取消后释放引用，退出后重试须重新输入。
7. 批次摘要分别统计等待、运行、成功、失败、取消和中断。可集中重填最近一批的失败项，重新输入密码；成功输出旁可打开其所在文件夹。
8. 启动后主动提示需要处理的中断记录。**中断任务临时数据 / Interrupted task data** 区分正在运行、可清理及记录异常，正常记录展示源、输出和临时路径。清理失败保留记录；解除占用后再清理。异常记录请先备份并核查，应用不会据此猜测删除位置。不支持断点续传；请同时检查最终输出是否已生成。
9. 操作报错后展开 **错误详情与诊断 / Error details & diagnostics**，可复制详情或主动导出 JSON。报告只包含版本、平台、时间、错误类别、操作及系统错误号，不包含密码、密钥或本机路径；导出不会覆盖已有文件。

加密后源数据仍然保留，应用不会自动删除原件。密码遗失无法恢复。界面与应用生成的文件选择标题遵循语言选择，Windows 文件对话框的系统按钮和系统错误由操作系统语言决定。

**文件保护** 页面提供“不保护、隐藏、锁定、只读属性、权限只读、隐藏并锁定”六种方式，默认隐藏并锁定。顶部添加文件或文件夹，也可在本页拖入；逐项填写区分备注、确认方式后点击“应用保护”，选择不会立即修改文件。列表支持按全部最外层名称和自定备注搜索，同名项目分别保留。修改登记方式后点击“应用更改”，或“解除保护”以恢复原状；选中当前页项目可批量核验及确认后解除。隐藏设置 Hidden + System 属性；锁定使用 NTFS DACL 限制当前 Windows 账户读取、写入、目录枚举和新建子项，权限只读保留读取及枚举并限制写入、新建和目录内删除，恢复仍由该账户操作。具体边界见[保护方式](docs/LOCKING.md)。

列表中的“登记方式”来自本地恢复记录，不能当作实时保护状态。“核验”只比较已登记内容的属性、锁定身份与权限，返回与记录一致、存在变更或无法核验；不扫描新增子项，也不代表持续防护。刷新失败时保留上次列表并暂停项目操作，刷新成功后可继续。保护操作结果和列表刷新结果分别报告，成功反馈留在项目附近。

管理记录存储于 `%APPDATA%\FoldSentinel\state.json`，包含原始属性、DACL、继承标记、文件身份和可选的用户备注；解除保护前请保留此文件。备注最多 80 个字符，旧版 v3 工具仍可读取恢复字段，但再次保存可能丢弃不认识的备注。记录未加密，不代表文件权限未被外部修改。普通解除遇到权限或身份冲突时会停止，不会静默覆盖冲突权限。

解除保护只有原有入口。若发现权限冲突，程序会自动只读核查；通过后在同一行要求确认。确认会恢复保护前权限，撤销保护后新增或修改的权限（包括资源管理器“继续”授予的访问权限），文件内容不变。核查后记录或权限再次变化会使确认失效；文件替换、缺失或父继承冲突仍会停止。详见[恢复说明](docs/LOCKING.md)。

恢复列表显示最外层文件或文件夹名称、备注、登记方式、核验摘要及项目操作，不显示完整路径、内部文件名、子项明细或状态文件位置。后台接口只传递这些摘要白名单字段和内部定位标识；点击恢复由后台读取本地记录定位目标。完整路径和逐项原始属性仍保存在本机 JSON 中，记录本身尚未加密。CLI `status` 保留逐项属性排查功能，图形页面不展示这些明细。

最外层路径索引与逐项原始属性一起在本机持久化，关闭或重启后保留。首页显示恢复入口，可按最外层名称直接恢复该项目及已登记子项，无需在资源管理器中重新找到隐藏内容；不会回填完整路径。旧记录自动推导最外层路径，父子合并且重复去重；只有显式恢复完成才移除对应记录，刷新不会因路径离线自动清空。同名项目分别保留，名称相同也不会合并恢复。

本地恢复入口未登记的新子项不会自动受保护，其他账户或预先打开的句柄仍可能创建它们。Readonly 属性不对文件夹提供写保护。当前源码接受 v1/v2/v3 属性记录，显式操作后保存 v3 状态（独立的 v1 锁定记录）；不兼容v3的旧程序会拒绝读取。降级前请用新版恢复全部项目并备份状态。旧版隐藏加只读策略仍可恢复和通过 CLI 使用。

独立的 **SYSTEM 服务与密码访问** 入口通过经过Windows令牌鉴权的本机服务登记项目，支持密码验证后临时解锁、立即重锁、密码修改与持续防护开关。临时解锁默认5分钟；关闭主窗口不停止服务，重启服务先处理未完成访问。服务扫描新增项和权限变化存在检测间隔，不能撤销既有句柄。服务状态和本地恢复记录分开，不自动迁移旧ACL；需要先在旧入口解除，再明确登记。服务二进制和安装脚本随便携包提供，**安装前须明确确认；本机已完成真实SYSTEM及SCM生命周期测试，第二账户和整机重启仍待验证**，说明见[持续防护服务](docs/SERVICE.md)。

安装版在 Windows“已安装的应用”中提供卸载入口，安装目录也包含 `uninstall.exe`。正常卸载前须在本软件中恢复全部登记的加密项目、关闭本地及全部账户的服务文件保护，并处理完中断任务。卸载器检查独立资产清单及当前账户桌面、文档、下载和本软件数据目录；发现待恢复加密包、缺失或不可访问的恢复输出、扫描失败时停止。标准目录遵循 Windows 重定向配置，包括 OneDrive；此范围不是所有账户、所有磁盘的全机内容扫描，其他旧包目录可先用 CLI `vault discover` 扫描登记。交互式强制卸载同窗显示中英免责声明并要求二次确认，默认选择“否”；静默或被动模式不允许强制。强制路径移除应用和独立服务，但保留加密包、保护状态和全部恢复资料，文件可能仍受保护，后续需重新安装或使用恢复工具处理。服务删除需要管理员授权，取消或失败会停止卸载。完整操作与数据保留规则见[卸载说明](docs/INSTALL.md#卸载前检查与强制卸载)。

## 功能与边界

- Argon2id 派生密钥，RustCrypto STREAM BE32 + AES-256-GCM 分块认证加密；随机 salt/nonce 前缀，每块认证整个格式头部及顺序、终块状态。
- 文件与文件夹均支持，目录包含相对结构、Unicode 文件名和空目录；错误密码、篡改或截断不会生成恢复输出。
- **v2 文件内容总量最多 1 TiB、目录最多 100,000 项**，固定 1 MiB 分块，不压缩；单路径最多 4096 UTF-8 字节、相对路径总量最多 16 MiB。内容内存不随文件大小增长，目录清单内存有上限。这是格式/实现限制，实测规模见验证记录。
- 新建加密包使用 v2，兼容恢复 v0.1 的 v1 加密包；v0.1 无法读取 v2。旧包仍受 v1 的 64 MiB / 10,000 项限制。
- 拒绝覆盖任何已有输出；源文件和加密包均保留。属性操作提前持久化恢复记录，互斥锁防止多个进程覆盖状态。
- 拒绝目录联接、符号链接及其他重解析点。操作期间请勿改动源数据；不提供文件系统快照。
- 加密目录保留内容及结构，**不保留 NTFS ACL、备用数据流、硬链接、原始时间戳或其他特殊元数据**。不适合系统目录、程序目录和完整备份。
- 不含内核 minifilter、透明挂载、原位加密、安全擦除或密码找回。系统服务是可选安装项，密码限制本应用的服务接口，所有者、同账户程序及管理员仍可能更改DACL；需要内容机密性时使用加密包。不是 Anvi 的格式兼容实现。
- 自有容器格式尚未经过独立安全审计。临时恢复明文、进程中断和内存清理的具体边界见 [格式说明](docs/FORMAT.md)。

## 开发与构建

Windows 环境需要当前 Rust stable（MSVC）、Visual Studio C++ Build Tools、Windows SDK、Node.js 22.12+ 和 WebView2。依赖版本锁定于 Cargo.lock 和 package-lock.json；桌面依赖仅用于 UI 构建，核心 CLI 可单独构建。

```powershell
cargo run -- state-path
cargo run -- protect C:\Private\Notes --mode hidden-locked
cargo run -- status C:\Private\Notes
cargo run -- unprotect C:\Private\Notes
cargo run -- vault encrypt C:\Private\Notes C:\Private\Notes.fse
cargo run -- vault decrypt C:\Private\Notes.fse C:\Private\Notes-restored
cargo run -- vault verify C:\Private\Notes.fse
cargo run -- vault discover D:\OldVaults E:\Archive
cargo run -- vault inventory
cargo run -- vault interrupted
cargo run -- vault cleanup <中断任务ID>
cargo run -- managed status
cargo run -- managed enroll C:\Private\Notes --mode hidden-locked --password
cargo run -- managed list
cargo run -- managed unlock <服务项目ID> --seconds 300
cargo run -- managed relock <服务项目ID>
cargo run -- managed continuous <服务项目ID> off --password
cargo run -- managed remove <服务项目ID> --password
cargo test -p foldsentinel
cargo clippy --workspace --all-targets -- -D warnings
npm ci
npm test
npm run tauri dev
npm run tauri build
```

CLI 通过终端无回显输入密码，不支持把密码放进命令行参数；进度输出到标准错误，Windows 终端 Ctrl+C / Ctrl+Break 请求安全取消。默认 `cargo run` 运行 CLI；桌面开发使用 `npm run tauri dev`。桌面程序为 `FoldSentinel.exe`，命令行为 `foldsentinel-cli.exe`，位于 `target/release/`，安装器位于 `target/release/bundle/nsis/`。

核心在 `src/`，桌面桥接在 `src-tauri/`，TypeScript 界面在 `ui/`。格式与兼容性约定见 [格式说明](docs/FORMAT.md)。

Windows CI 执行版本一致性、真实 IO、隔离小卷写满与安装升级检查，并保留报告和安装包、便携包。手动执行 `./scripts/package.ps1` 可完成构建、打包、内容检查和 SHA-256 生成，结果位于 `artifacts/<版本>/`。发布附件与 CI 结果以对应提交的 Release 为准；本机已验证内容、重现命令及未覆盖场景见 [验证记录](docs/VALIDATION.md)。

安装、升级、便携版数据位置与校验方式见 [安装与发布](docs/INSTALL.md)。磁盘空间预检采用保守估计，不能保证其他程序随后不占用空间；运行中仍会明确报告写入失败。JavaScript 字符串无法保证原地清零；Rust 密码与明文缓冲使用 Zeroizing，前端仅保留当前队列所需的内存引用。
