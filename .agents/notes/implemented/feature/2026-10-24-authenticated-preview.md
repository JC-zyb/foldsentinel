# Agent Note: 完整认证后的有界内容预览

Status: implemented

## Problem

用户在恢复前无法确认加密包中的目录、文件和大小。只读取格式头或提前显示解析到的条目会让未完成认证、截断或损坏的包看起来可信；恢复到临时目录再查看则会留下明文。

## Decision

复用现有 v1/v2 验证及恢复解析器，在只读验证时收集有界条目摘要。仅在完整认证、归档校验、终块及物理 EOF 检查成功后向调用方返回预览。完整条目和内容仍全部验证；展示上限不等于验证上限。

预览不创建临时目录或恢复文件，不改格式，不保存密码、条目清单或密钥到历史。桌面展示总量及有限条目并分页；超限时明确提示仅展示部分内容。失败、取消或更换待查看任务时清除旧预览，防止将旧结果误认为新包结果。

历史审计：[双语任务](../../implemented/architecture/2026-10-24-daily-workflows.md) 部分重叠，沿用队列和只读验证；[流式格式](../../implemented/architecture/2026-10-24-streaming-v2.md) 部分重叠，保持认证与提交边界；[发布门禁](../../implemented/process/2026-10-24-release-gates.md) 无运行时重叠，保留环境证据约束。现有属性恢复笔记无关。

## Alternatives considered

- 恢复到临时目录后列出内容能复用文件系统浏览，但需要磁盘空间并留下恢复明文；采用解析时仅收集元数据。
- 验证过程中实时显示路径能更快反馈，但完整包可能随后认证失败；仅在整包验证成功后发布结果。
- 返回全部条目便于浏览，但会放大 IPC、DOM 和内存占用；完整验证、有限展示，并显式报告截断。

## Testing

- v1/v2 文件与目录包、Unicode、空目录均可验证并预览，不生成输出或任务登记。
- 错误密码、篡改、截断、取消、非法归档不得返回成功预览。
- 展示条目及名称字节数有界；分页、总量和省略提示正确，中英切换不重启任务。
- 旧格式和任务历史兼容，UI 优化有双语及窄窗口证据；干净系统验证缺少环境时明确记为未执行。

## Consequences

复用解码和归档检查避免验证与恢复的规则分叉；完整扫描意味着大包必须等待整包验证结束。只保留前 1,000 项和 256 KiB 路径名，每页 50 项，总量独立统计，展示有界而验证不跳过剩余内容。单文件格式不存原名称，用空路径明确这一限制。

文件内容可以不落盘，但条目名称仍是敏感信息，只在本机内存中展示，进度不发送未完成认证的条目路径。JavaScript 无法保证原地清零。缺少 WebView2 的系统行为需要独立环境，普通 runner、浏览器 DPR 或模拟夹具不能替代。
