# Agent Note: 独立的 NTFS 锁定模式

Status: implemented

## Problem

Hidden/System 只影响文件显示，Readonly 对文件夹不提供写保护。用户希望在日常操作中阻止修改、删除或访问，但当前属性页不能提供这种访问控制。将权限改动混入隐藏会扩大恢复风险，也不能得到可靠的密码机密性。

## Decision

锁定与隐藏、只读分别建模，UI 提供不保护、隐藏、锁定、只读、隐藏并锁定，默认隐藏并锁定。截图中锁定与只读为不同选项，因此锁定拒绝当前用户 SID 的内容读取 / 写入、目录枚举、新建子项、文件执行、DELETE 和目录 DELETE_CHILD。保留 READ_CONTROL、WRITE_DAC、元数据访问与目录穿越以供恢复。相同账户可以解除锁定；不提供密码隔离或“只有本程序可解除”的承诺。加密包继续承担内容机密性。旧 hidden-readonly 模式保留兼容，新选择器只在读取该旧记录时提供它。

属性状态升级为 v3，接受 v1/v2，旧程序拒读新版。每条 ACL 恢复数据使用独立 version=1，保存原始 / 预计算的锁定 DACL（SDDL）、继承保护控制、范围外父 DACL、卷序列号、文件 ID 与创建时间，不复用属性掩码。完整计划先持久化，再改权限，任意阶段失败仍保留恢复所需的原始及计划状态。已恢复的原始 ACL 也视为可重试状态。文件身份、DACL 或范围外父继承变化会停止，不覆盖冲突；锁定路径缺失时保留记录。

使用 Windows SetSecurityInfo / GetSecurityInfo 及持有的文件句柄；预检时打开权限句柄并禁止共享删除，避免登记至写入期间路径替换。子项先锁定并禁用继承，再锁父项；锁定副本去掉继承传播标记，避免误改范围外对象。恢复先父后子，恢复原始 DACL 与是否继承；忽略 AI/AR 自动继承计算标记比较，但不忽略 ACE 或 P 继承保护位。禁止单独解除锁定祖先内的子项。父目录扩大保护时枚举未锁定部分，并合并已登记的锁定子树，不遗漏兄弟项。

不修改所有者、SACL、系统目录、用户配置根、恢复资料目录或程序自身，不部署驱动或服务；多硬链接、重解析点及非 NTFS 在修改前拒绝。GUI 通过内部标识切换策略，仅返回名称和模式，不传递完整路径、子项或 ACL。

设计依据：Windows 根据线程令牌和对象安全描述符授予访问；父目录 ACL 不直接决定每个已有子对象的权限，继承、既有句柄和父目录删除权限需要分别测试。[File security and access rights](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights)。空 DACL 与无 DACL 含义相反，ACE 顺序和组成员权限会影响结果，不能使用 Everyone Deny 一概处理。[DACLs and ACEs](https://learn.microsoft.com/en-us/windows/win32/secauthz/dacls-and-aces)。备份 / 恢复特权和管理员恢复能力必须作为边界列出，不能以本机单一令牌实验替代多账户验收。

历史审计：[属性状态](../../implemented/feature/2026-10-27-attribute-status.md) 与[属性恢复](../../implemented/bug-fix/2026-10-24-recoverable-attributes.md) 部分重叠，仅复用显式状态与先登记原则，不能直接复用掩码恢复；[加密边界](../../implemented/architecture/2026-10-24-vault-and-desktop.md) 部分重叠，保留内容加密，锁定不替代它。没有完全吸收或废弃旧笔记。

权限漂移后的独立自助出口见[显式确认恢复](../../implemented/bug-fix/2026-10-27-reviewed-acl-recovery.md)；默认解除仍保留本篇的严格冲突停止原则。

## Alternatives considered

- 只用现有只读属性实现最简单，但目录不受其写保护，无法满足防删除 / 防写入；保留属性功能并单独评估 ACL。
- 对 Everyone 拒绝所有访问容易制造锁定效果，但也可能阻止本程序恢复，而且并不隔离相同令牌的不同应用；不采用此默认策略。
- 内核过滤驱动能拦截目录枚举和文件 IO，但增加签名、安装、系统兼容和故障恢复成本；本阶段不实现。

## Consequences

- 自有临时 NTFS 文件测试覆盖内容读取 / 写入、目录枚举和新建拒绝、既有句柄仍可读、中文子树恢复、策略切换与重启、保存失败不改权限、已登记但未完成写入的恢复、外部 ACL / 文件身份冲突、父继承变化、缺失路径、硬链接及扩大父目录。源内容和原始 DACL 在恢复后核对。
- 锁定不需要额外依赖或管理员服务，但预检持有每个对象的句柄，资源开销随已有项目数量增长；遇句柄或权限限制时在修改前停止。保护记录仍未加密，必须保留用于恢复；降级前先恢复。
- 同一账户、管理员、备份 / 恢复特权及离线访问均不是隔离边界。其他账户与预先打开的句柄不受 SID 拒绝限制。父目录 DELETE_CHILD 仍可能允许删除 / 移动根项目，故不承诺绝对防删除，也不修改范围外父目录。未登记的新子项不自动受保护。
- 当前没有干净 Windows 虚拟机、第二个账户或本次原生 DPI 验证，不能据单账户 NTFS 测试宣称多账户 / 干净系统验收通过。该实现为本地开发功能，现有 v0.6.0 发布包仍是原属性版。
