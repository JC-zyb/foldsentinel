# Agent Note: 文件保护工作区与显式核验

Status: implemented

## Problem

最外层记录中的保护方式只是登记意图，不能证明磁盘上的属性或权限仍与记录一致。刷新失败前清空列表会使恢复入口消失，操作后的刷新错误还可能覆盖原操作失败。添加入口位于长列表下方、操作结果跳到页尾及保护页拖放切换到加密页，令用户难以确认自己正在修改哪个项目。同名项目仅凭名称不能区分，而重新显示父路径会违反既有隐私边界。

## Decision

文件保护使用顶部添加入口、紧凑待保护面板及最外层项目列表。选择和拖放只产生待保护选择，用户明确应用才修改属性或权限；拖放按当前页面处理。行内反馈保留操作上下文，模式变化标记未应用，混合模式先选具体方式。重复应用明确说明处理范围，不承诺监控新增内容。

元数据刷新与显式核验分开。刷新只读取恢复索引，并按全部最外层名称与用户备注搜索后分页；返回过滤数量及全部记录数量，不扫描文件系统。核验只检查已登记内容，聚合为与记录一致、存在变更或无法核验及核验时间，不向 UI 返回路径、子项名称、ACL 明细。未经核验显示未核验，不把登记方式或记录数量标为实时防护结果。

刷新过程中保留上一次成功记录；失败标记过期，保留恢复提醒和重试入口，并暂禁基于过期视图的操作。保护动作和刷新分别捕获结果，刷新失败不能覆盖原操作错误，也不能把已经成功的保护改写为失败。没有取消实现的操作不显示可取消。

用户可为最外层项目保存最多 80 个 Unicode 字符的区分备注，拒绝控制字符。备注与现有恢复状态在同一持久化边界保存，使用可缺省元数据兼容旧 v3 记录；空备注清除，不自动生成包含父路径的备注。未保存的备注草稿在行重建和失败反馈期间保留，只有保存成功或用户取消才清除。备注不作为路径或权限凭据。

历史审计：[最外层名称恢复列表](../../implemented/feature/2026-10-27-private-recovery-list.md)部分重叠，保留名称隐私、后台解析标识及单份恢复状态，本篇扩展备注和只含聚合结果的显式核验；[属性状态](../../implemented/feature/2026-10-27-attribute-status.md)部分重叠，复用只检查登记内容及不自动修复原则，不恢复图形逐项披露；[NTFS 锁定](../../implemented/feature/2026-10-27-ntfs-locking.md)部分重叠，复用文件身份和 DACL 检查，不改变锁定策略。双语任务、加密预览和发布门禁仅共用页面或验证工具，没有需要完全吸收或删除的决定，也没有命中的 rejected 提案。

## Alternatives considered

- 进入页面自动核验全部路径可以直接展示状态，但会让离线位置和大量登记内容的 IO 阻塞普通恢复索引读取；保留快速元数据列表，核验由用户明确触发。
- 继续显示父路径最容易区分同名项目，但会重新把位置及内部信息暴露到 DOM 和可访问性树；使用用户自定备注，并在同名时提示设置备注。
- 将备注另存 localStorage 可避免核心格式变化，但会与原恢复记录脱节且不能随恢复状态一起迁移；在现有状态中增加默认可缺省字段。
- 任何异步错误都显示到同一页尾结果区可以复用旧逻辑，但会混淆保护结果和刷新结果，也会抢走行操作焦点；拆开两个结果并就地显示。

## Verification

前端 12 项测试通过，新增测试覆盖加载中保留旧快照、重叠刷新拒绝、刷新失败后重试清除过期状态，以及操作和刷新失败的四种组合。浏览器 48 组布局及组件检查通过：中英文、1080/720/576/480 CSS 宽度及 1/1.25/1.5 代表 DPR，覆盖添加入口首屏可见、取消清空路径、名称展开、混合方式先选后应用、未应用提示、80 Unicode 字符备注边界、过期记录禁用动作和行回调保留焦点。DOM 与可访问性检查继续拒绝父路径和内部名称，合成数据不接入桌面 IPC 或模拟文件操作成功。后端 55 项核心及 6 项桌面测试覆盖搜索、备注保存与失败回滚、核验范围与属性 / ACL / 身份变化。隔离的独立桌面 UI 验收确认同名项目、备注保存与搜索、属性变化核验、新添加的隐藏并锁定、重启记录保留及解除后内容恢复；夹具最终全部恢复。报告及后端检查结果记在 [验证记录](../../../../docs/VALIDATION.md)。

## Consequences

登记与核验分开使快速恢复入口不受文件系统核验 IO 影响；刷新失败保留记录且不会覆盖真实操作结果，用户可在行内处理模式和备注。代价是需要额外的显式核验操作、用户需自行提供有意义的区分备注，并且页面维护登记快照、核验时间和反馈三类状态。核验只证明读取时刻已登记内容与记录相符，不能证明所有进程都被限制，也不扫描新子项。备注由用户输入，不能宣称它不包含用户主动填写的敏感内容。本轮浏览器布局和状态测试不能代替 Windows 原生缩放、真实桌面 IPC、干净系统或安装升级验收。密码访问、权限只读和持续拦截不在本轮范围。
