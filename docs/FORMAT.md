# FSEAL v1 文件格式

文件扩展名建议为 `.fse`。这是 FoldSentinel 自己的容器格式，不兼容 Anvi Folder Locker 或其他产品。算法由 RustCrypto 实现；本项目未经过独立安全审计。

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 8 | ASCII `FSEAL001` |
| 8 | 1 | 版本，固定为 1 |
| 9 | 1 | 内容类型：0 普通文件，1 未压缩 tar 目录归档 |
| 10 | 16 | 操作系统随机生成的 salt |
| 26 | 12 | 操作系统随机生成的 AES-GCM nonce |
| 38 | 可变 | AES-256-GCM 密文及尾部 16 字节认证标签 |

密钥使用 Argon2id v0x13 从密码 UTF-8 字节派生。v1 固定参数为 m=19456 KiB、t=2、p=1、输出 32 字节；升级参数必须使用新格式版本，不能随依赖默认值改变。38 字节头部全部作为 AEAD associated data 认证。每次加密重新生成 salt 和 nonce；加密包不包含密码或派生密钥。

明文文件或完整 tar 归档最大为 64 MiB。目录最多 10,000 项，支持 Unicode 名称和空目录。归档保存文件内容和相对目录结构；恢复不重建 NTFS ACL、ADS、稀疏布局、硬链接、原始时间戳或 EFS 信息。不要用首版代替完整备份工具。目录遍历拒绝符号链接、目录联接和其他重解析点；源数据应在操作期间保持静止，不提供文件系统快照。

解密先在内存中验证完整标签，认证失败不会创建明文输出。恢复目录仅接受相对普通路径、普通文件和目录，拒绝设备名、路径穿越、重复路径、链接、特殊文件及超出限额的内容。输出文件使用同目录随机临时文件、`sync_all` 和禁止覆盖的提交；目录在同目录临时位置完整恢复后使用 Windows `MoveFileExW(flags=0)` 提交，禁止覆盖现有位置。

普通错误由临时对象清理。断电、强制终止或删除失败可能留下临时文件夹，其中可能包含已认证的恢复明文；临时文件不是安全擦除机制。输出继承目标目录的访问权限。内存中的核心明文、派生密钥及 Rust 端密码用 `Zeroizing` 清理，但 WebView、系统交换文件、其他进程及硬件的内存副本不在此保证内。
