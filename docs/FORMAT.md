# FSEAL 文件格式与任务边界

文件扩展名建议为 `.fse`。这是 FoldSentinel 自己的容器格式，不兼容 Anvi Folder Locker 或其他产品。算法由 RustCrypto 实现；本项目未经过独立安全审计。

v0.2 新建包使用 v2，同时保留 v1 解码；v0.1 只能读取 v1。

## v2 头部（46 字节）

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 8 | ASCII `FSEAL002` |
| 8 | 1 | 版本，固定为 2 |
| 9 | 1 | 内容类型：0 普通文件，1 未压缩 tar 目录归档 |
| 10 | 16 | 操作系统随机生成的 Argon2 salt |
| 26 | 7 | 操作系统随机生成的 STREAM nonce 前缀 |
| 33 | 1 | chunk log2，固定为 20（1 MiB） |
| 34 | 8 | 内容总字节数，小端 u64；目录不含 tar 元数据和填充 |
| 42 | 4 | 目录逻辑条目数，小端 u32；文件必须为 0 |

密钥使用 Argon2id v0x13、m=19456 KiB、t=2、p=1、输出 32 字节，从密码 UTF-8 字节派生。每次独立加密重新生成 salt 和前缀；参数不随依赖默认值改变，包不包含密码或派生密钥。

## v2 分块

使用 RustCrypto `aead 0.5` 的 `EncryptorBE32<Aes256Gcm>` / `DecryptorBE32<Aes256Gcm>`。每块 AAD 为完整 46 字节头部。STREAM 构造的 12 字节 nonce 为 7 字节前缀、4 字节大端递增计数器、1 字节 last 标记，认证块顺序及终块状态。实现上限低于计数器极限。

每帧先写入小端 u32：最高位表示 last，其余 31 位为后续密文长度（包含 16 字节标签）。非终帧必须恰好为 1 MiB + 16 字节；终帧为 16 至 1 MiB + 16 字节。编码器遇到完整 1 MiB 块立即写非终帧，结束时总是写终帧；整倍数内容仍有空明文终帧。

读取必须验证全部帧、last 标签及物理 EOF。缺终帧、错序、修改头部/密文/标签、重复块和追加数据均拒绝。帧长度先检查再分配，内容内存有界。文件恢复大小必须等于认证头部声明；目录还校验逻辑条目数、内容总量、条目类型、相对路径和 tar 尾部。tar 的零头部 EOF 不等同于认证 EOF，必须继续验证终帧，且剩余填充不超过 1024 个零字节。

文件内容总量最多 1 TiB，目录最多 100,000 项，单相对路径最多 4096 UTF-8 字节，总相对路径最多 16 MiB。目录通过有界清单保存相对名称、大小和修改时间；内容不整包加载内存。tar 长文件名扩展不是逻辑条目。不压缩，不保留 NTFS ACL、ADS、稀疏布局、硬链接、原始时间戳或 EFS 信息。

v2 解码使用 raw tar 条目，只接收普通文件/目录和紧邻其前的单个 GNU 长名称扩展（最多 4097 字节，含结尾 NUL）；先检查扩展大小再读取。PAX、稀疏表和其他扩展拒绝，避免在路径限额校验前无界解析元数据。

## 源数据、取消与提交

拒绝已有输出、路径穿越、设备名、链接、目录联接、重解析点和特殊文件。加密目录预扫描，逐个文件读取前后核对大小和修改时间，读取时 Windows 文件共享模式拒绝并发写入/删除句柄，结束后再扫描目录核对变化。**不提供文件系统快照**：之前已读完的文件仍可能随后改变，不适合系统目录或一致性备份。

输出先写到目标父目录中的随机 `.foldsentinel-job-*` 临时目录。恢复把已认证分块的明文写到临时目录，完整流和归档验证通过后才提交最终位置。文件写入 `sync_all`，目录中的普通文件也逐一同步。Windows `MoveFileExW(flags=0)` 同卷提交，禁止覆盖文件或文件夹。

取消检查覆盖扫描和 IO 分块；Argon2 计算及系统 IO 调用期间可能延迟响应。最终取消检查与提交共享原子状态门：先接受取消则不提交，提交先开始则拒绝取消。UI 在提交阶段禁用取消。关闭桌面窗口会阻止本次关闭并请求取消，结束后可再次关闭；CLI 使用 Windows 控制台 Ctrl+C / Ctrl+Break。

## 中断任务

`%APPDATA%\FoldSentinel\jobs\<id>.json` 保存版本、任务 ID、源路径、输出路径、临时路径和方向，不保存密码或密钥。所有者标记和登记先同步，登记文件通过不覆盖重命名发布，之后才写 payload。`active.lock` 在处理期间持有排他锁。正常成功、错误或取消显式清理；清理失败返回错误并保留记录。

异常退出后列出非活跃任务；清理前验证记录、同一输出父目录、所有者标记、非重解析路径及活动锁。只删除该任务的临时目录和登记，源文件及最终输出不参与删除。已提交但尚未清理的任务也可能出现，应先检查最终输出。UI 清理后重填路径，CLI 提供 `vault interrupted` 和 `vault cleanup <id>`；重新处理需要再次输入密码。

**不做断点续传，不承诺断电事务、磁盘故障恢复或安全擦除。** 突然掉电在登记完成前可能留下空临时目录，目录同步不保证所有硬件持久化语义。临时恢复明文继承目标目录权限，仍可被其他有权限的程序访问。核心缓冲区、派生密钥及 Rust 端密码用 `Zeroizing` 清理，但 WebView、操作系统、交换文件、硬件和其他进程的副本不在保证范围内。

## v1 兼容格式

以下保留 v0.1 的格式及解码约定。v0.2 通过任务临时目录包装旧解码器，沿用取消提交门和中断清理；旧算法、参数及头部保持兼容。旧解码阶段不提供精细字节进度，取消在旧解码返回后、最终提交前生效。

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 8 | ASCII `FSEAL001` |
| 8 | 1 | 版本，固定为 1 |
| 9 | 1 | 内容类型：0 普通文件，1 未压缩 tar 目录归档 |
| 10 | 16 | 操作系统随机生成的 salt |
| 26 | 12 | 操作系统随机生成的 AES-GCM nonce |
| 38 | 可变 | AES-256-GCM 密文及尾部 16 字节认证标签 |

密钥使用 Argon2id v0x13 从密码 UTF-8 字节派生。v1 固定参数为 m=19456 KiB、t=2、p=1、输出 32 字节；升级参数必须使用新格式版本，不能随依赖默认值改变。38 字节头部全部作为 AEAD associated data 认证。每次加密重新生成 salt 和 nonce；加密包不包含密码或派生密钥。

明文文件或完整 tar 归档最大为 64 MiB。目录最多 10,000 项，支持 Unicode 名称和空目录。归档保存文件内容和相对目录结构；恢复不重建 NTFS ACL、ADS、稀疏布局、硬链接、原始时间戳或 EFS 信息。不要用首版代替完整备份工具。目录遍历拒绝符号链接、目录联接和其他重解析点；源数据应在操作期间保持静止，不提供文件系统快照。

解密先在内存中验证完整标签，认证失败不会创建明文输出。恢复目录仅接受相对普通路径、普通文件和目录，拒绝设备名、路径穿越、重复路径、链接、特殊文件及超出限额的内容。输出文件使用同目录随机临时文件、`sync_all` 和禁止覆盖的提交；目录在同目录临时位置完整恢复后使用 Windows `MoveFileExW(flags=0)` 提交，禁止覆盖现有位置。

普通错误由临时对象清理。断电、强制终止或删除失败可能留下临时文件夹，其中可能包含已认证的恢复明文；临时文件不是安全擦除机制。输出继承目标目录的访问权限。内存中的核心明文、派生密钥及 Rust 端密码用 `Zeroizing` 清理，但 WebView、系统交换文件、其他进程及硬件的内存副本不在此保证内。
