## 问题与改动

- 默认窗口原提交按钮顶部约 y=934，超出 820px 首屏。来源和密码改为自适应双列后，最终预览中约 y=675，整个按钮位于首屏。展开手动路径、长清单或中断提醒后仍按正常文档流滚动，不保证所有内容始终位于首屏。
- 移除 1000px 视口下无条件折行路径和密码的规则，以实际主内容宽度决定表单列数。960px 以下采用紧凑横向导航；保护列表独立按可用宽度使用三列、双列卡片或单列卡片。
- 窄窗口中添加组三个入口占独立一行，服务入口和刷新在下一行。保护模式的英文旧版选中值在中小窗口完整显示。
- 必要输入框及次级按钮轮廓由语义变量统一控制，悬停状态也保留清晰边界。辅助说明从 12px 调为 13px；保留原有 44px 主要操作目标、焦点轮廓与减少动画设置。
- 全局结果移至页首；普通状态不抢焦点，错误仍可聚焦。导航后聚焦新页面标题，主内容与操作组提供可访问名称。浏览器预览明确说明本机记录须在桌面程序读取。
- 服务重绘保留说明展开状态及 summary 焦点；长列表下方触发编辑器时，首个输入自动进入视口。末项记录的底角单独圆角处理，避免裁剪键盘焦点轮廓。
- 队列运行中“查看队列”聚焦稳定标题；任务重建按任务 ID 与动作保留焦点，原动作消失时返回标题。服务刷新在禁用按钮前保存焦点，并尊重用户刷新期间的主动焦点转移。无输入的恢复/监控确认表单打开后聚焦可见确认控件，取消后返回原记录并滚入视口。
- 暂停请求在队列旁显示独立状态提示，按钮禁用防止重复请求；当前任务完成后保留等待项，继续执行时清除提示。切换页面清除上一页的全局操作反馈，避免加密队列提示出现在文件保护页。
- 明暗主题跟随系统偏好，覆盖输入、队列、记录、预览与成功/警告/错误状态。深色主按钮填充与链接色分别定义，保留按钮白字对比；导航使用适合深蓝背景的青色焦点。强制配色下以系统色实线下划线标识选中项，以独立轮廓标识键盘焦点。

桌面示意：

```text
导航 │ 页面标题                                  语言
     │ 创建加密包 / 恢复 / 验证
     │ ┌─ 1 选择内容 ─────────┬─ 2 密码 ──────────┐
     │ │ 文件、文件夹、输出位置 │ 密码、确认、安全说明 │
     │ ├─────────────────────┴────────────────────┤
     │ │ 3 确认并排队                  加入队列     │
     │ └──────────────────────────────────────────┘
     │ 当前任务 → 开始/暂停 → 历史
     │ 中断数据与辅助说明
```

窄窗口按来源→密码→确认的顺序单列排列，保护项目按名称、登记方式、核验与操作排列。

## 验证结果

- `npm run build`：TypeScript 与生产构建通过。
- `npm test`：17 项工作流、历史、保护状态和双语契约测试通过。
- `scripts/validate-ui.mjs`：92 组检查通过，生成 90 张截图。CSS 宽度为 375、480、576、720、900、960、961、1080、1440px，包含代表性的 1、1.25、1.5 DPR；每组覆盖中英界面及加密、恢复、验证、保护列表。
- 增加默认提交首屏可见、操作组名称、导航焦点及选中模式文字宽度断言；保留输入与密码跨语言切换、长路径、名称展开、显式模式提交、备注与刷新状态、隐私字段及键盘焦点检查。
- 使用真实服务 UI 组件和独立合成布局数据，验证说明展开/收起及焦点跨重绘保留、20 项列表末项打开编辑器后首输入完整进入视口。测试入口禁止 IPC 和文件操作，不模拟文件保护成功。
- 两轮独立静态审查和代表截图复审，确认首屏、窄窗口工具栏及模式文字问题已解决。
- `scripts/validate-ui-states.mjs`：14 组动态回归通过，使用真实队列和服务组件，覆盖开始/完成/取消重建、异步刷新、无输入编辑器、暂停和继续，以及切页清除旧反馈。合成执行器只用于可控等待和取消边界，不执行文件操作，不冒充原生文件操作成功。
- `scripts/validate-ui-themes.mjs`：168 项主题检查通过，156 张截图覆盖 375/720/1080px、明暗、中英、三种包操作、保护与服务展示状态。按实际祖先背景合成实测 7,348 处文字、168 处占位文字、1,440 处边界、3,108 处焦点；最低正文 4.626:1、边界 3.057:1、焦点 3.319:1。另运行新增的强制配色独立用例 1/1 通过，检查选中标识转移、独立焦点与尺寸不变。
- `cargo build -p foldsentinel-desktop --locked`：原生调试程序构建通过。在独立应用数据目录、WebView2 数据目录和测试文件目录中，通过原生窗口执行加密→验证预览→准备恢复→恢复；预览显示 3 文件、1 文件夹，恢复后的 3 文件与源文件 SHA-256 逐一一致。真实服务只读状态也能显示连接和空登记列表；未修改服务或真实文件保护。
